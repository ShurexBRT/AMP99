# AMP99 0.2.0-alpha.12

## Changes

- Fixed restoration of docked Equalizer and Playlist windows after minimizing Main.
- Restoring Main now listens to the native window focus event and unminimizes previously visible auxiliary windows.
- Opening a minimized auxiliary window now unminimizes it before showing it.
- Made the Main seek bar adapt vertically when the resizable Main window is taller.

## Owner test plan

1. Install or update from `0.2.0-alpha.11`.
2. Show Equalizer and Playlist, dock them to Main, then drag Main and confirm the docked group moves together.
3. Minimize Main and confirm the docked auxiliary windows minimize with it.
4. Restore Main from the taskbar and confirm both auxiliary windows are visible and usable.
5. Open Preferences, hide/show Equalizer or Playlist, and confirm a minimized window is restored instead of remaining inaccessible.
6. Resize Main vertically and confirm the seek bar moves with the layout rather than staying fixed near the display.
7. Confirm Spotify playback, OAuth state, playlist data, and close-to-tray behavior are unchanged.

# AMP99 v0.2.0-alpha.12

> Closed alpha · native window restore and responsive Main layout

## Summary

Alpha.12 fixes the docked-window restore path and makes the resizable Main seek bar follow the available vertical space.

## Changes

- Restores previously visible Equalizer and Playlist windows after Main is restored from minimize.
- Uses native Tauri focus events for Main restore handling.
- Unminimizes an auxiliary window before showing it again.
- Positions the Main seek bar responsively as Main becomes taller.

## Automated validation

- [x] Frontend tests: 5 files, 12 tests passed.
- [x] TypeScript/Vite production build.
- [x] Windows installer and native-window smoke test.
- [x] Unsigned Store MSIX preflight.

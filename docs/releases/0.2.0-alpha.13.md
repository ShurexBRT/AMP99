# AMP99 v0.2.0-alpha.13

> Closed alpha · auxiliary-window visibility state

## Summary

Alpha.13 fixes the case where Main showed Playlist as enabled while the native Playlist window was actually hidden, making the next `PL` click hide it again instead of showing it.

## Changes

- Initializes Main EQ/Playlist button state from the persisted native auxiliary-window state.
- Respects the EQ/Playlist restore-on-startup preferences when initializing Main state.
- Keeps the Main controls aligned with the actual native windows after startup restore.

# AMP99 v0.2.0-alpha.14

> Closed alpha · reliable Main/EQ/Playlist minimize and restore

## Summary

Alpha.14 fixes the native-window regression shown in the alpha.13 QA recording: after minimizing and restoring Main, the docked Equalizer and Playlist could remain hidden or become unreachable. AMP99 now keeps the native auxiliary-window visibility state synchronized and restores the visible windows together with Main.

## Changes

- Restores docked Equalizer and Playlist windows after Main is restored.
- Preserves independently hidden EQ/Playlist windows instead of forcing them visible.
- Synchronizes frontend visibility state with the native Rust window host.
- Adds native lifecycle recovery for minimize/restore and delayed focus/visibility transitions.
- Adds a Windows MSI regression smoke test covering Main, Equalizer and Playlist restore behavior.

## Manual Windows test plan

- [ ] Update from alpha.13 through `Preferences → Check for Updates`.
- [ ] Launch AMP99 and confirm Main, EQ and Playlist open according to their saved preferences.
- [ ] Dock EQ and Playlist to Main, minimize Main, then restore Main; both auxiliary windows must return visibly and remain docked.
- [ ] Repeat minimize/restore several times, including restoring Main from the taskbar.
- [ ] Hide EQ only, minimize and restore Main; EQ must remain hidden while Playlist follows its saved visible state.
- [ ] Hide Playlist only, minimize and restore Main; Playlist must remain hidden while EQ follows its saved visible state.
- [ ] Restore Main from the tray after minimizing; EQ and Playlist must not become unreachable or remain behind other windows.
- [ ] Confirm EQ/Playlist `PL` and `EQ` controls still match the actual native-window visibility.
- [ ] Confirm Spotify playback, OAuth, playlist data and close-to-tray behavior are unchanged.

## Known limitations

- Spotify Web Playback still depends on Spotify's active-device readiness and Premium account rules.
- This remains a closed alpha release and requires manual Windows QA on the target machine.

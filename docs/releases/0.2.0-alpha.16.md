# AMP99 v0.2.0-alpha.16

> Closed alpha · Stitch visual pass and interaction hardening

## Summary

Alpha.16 brings the approved AMP99 Stitch direction into the real three-window player while preserving the native Tauri architecture and legacy skin path.

## Changes

- Applies a graphite, amber and cyan visual system to the default Main Player, Equalizer and Playlist Editor surfaces.
- Preserves the 330×116 resizable default Main Player, 275×116 Equalizer and 275×232 Playlist Editor native window geometry.
- Reframes Preferences as a compact utility window with General, Playback, Spotify, Appearance, Hotkeys, Updates and About sections.
- Adds a functional queue filter while keeping Spotify queue indices and legacy `.wsz` Playlist geometry intact.
- Adds browser regression coverage for 2×, shade mode, queue filtering and Preferences navigation.
- Includes Stitch visual QA evidence and the handoff report in `design-qa.md`.

## Manual Windows test plan

- [ ] Raw `amp99.exe` starts and remains alive through the smoke observation window.
- [ ] MSI and NSIS installers are produced and install successfully.
- [ ] Main, Equalizer and Playlist are three separate top-level Windows windows in one AMP99 process.
- [ ] Main, Equalizer and Playlist can be moved independently and docked into the documented layout.
- [ ] Moving Main moves the connected docked group; pulling an auxiliary window away restores independent movement.
- [ ] Main shade mode changes the actual native window height and restores correctly.
- [ ] 1×/2× changes native dimensions and keeps controls usable.
- [ ] Main EQ/PL controls show and hide the corresponding native windows independently.
- [ ] Main close-to-tray, tray restore and explicit Quit behave correctly.
- [ ] Always on Top applies consistently to the full docked group and can be disabled.
- [ ] Default player controls, Playlist filtering, Preferences navigation and update check remain usable in the packaged app.
- [ ] A valid user-supplied `.wsz` skin synchronizes across all three windows; invalid input fails safely.
- [ ] Spotify OAuth, playback, playlists, Liked Songs, search and permitted playlist edits remain functional.

## Known limitations

- Spotify Web Playback still depends on Spotify active-device readiness and Premium account rules.
- Custom hotkey editing is intentionally not exposed in this alpha.
- This remains a closed alpha release and requires the native Windows QA matrix before public distribution.

## Upgrade

Use the signed updater from alpha.15, or download the installer from the [GitHub release](https://github.com/ShurexBRT/AMP99/releases/tag/v0.2.0-alpha.16).

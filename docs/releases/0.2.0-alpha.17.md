# AMP99 v0.2.0-alpha.17

> Closed alpha · windowing polish and Preferences usability fix

## Summary

Alpha.17 is a focused Windows QA build following alpha.16. It fixes the expanded Main Player seek layout and makes Preferences a wider, resizable native utility window.

## Changes

- Keeps the Main Player seek control vertically responsive when the native Main window is resized.
- Opens the native Preferences window at 520px wide instead of 390px.
- Allows Preferences to resize between 440×380 and 820×720 with a native SouthEast resize handle.
- Adds browser regression coverage for seek repositioning in an expanded Main Player.

## Known limitations

- Spotify Web Playback still depends on Spotify active-device readiness and Premium account rules.
- Custom hotkey editing is intentionally not exposed in this alpha.
- Manual Windows QA remains required before broader distribution.

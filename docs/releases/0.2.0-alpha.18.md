# AMP99 v0.2.0-alpha.18

> Closed alpha · Spotify playback reliability and responsive Main Player polish

## Summary

Alpha.18 is a focused Windows QA build following alpha.17. It fixes Spotify queue auto-next races, makes shuffle advance to a different queue item, and refines the resizable default Main Player layout.

## Changes

- Prevents duplicate or stale Spotify playback transitions when a track ends.
- Makes shuffle auto-next choose a different queue item instead of restarting the track that just ended.
- Keeps the Spotify playback error state from being caused by competing end-of-track commands.
- Moves the default Main Player volume slider outside the display and keeps it centered against the display as the player grows.
- Scales the default display and volume control proportionally with the resized Main Player.
- Adds regression coverage for queue navigation and the responsive display/volume layout.

## Known limitations

- Spotify Web Playback still depends on Spotify active-device readiness and Premium account rules.
- Custom hotkey editing is intentionally not exposed in this alpha.
- Manual Windows QA remains required before broader distribution.

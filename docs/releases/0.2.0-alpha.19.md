# AMP99 v0.2.0-alpha.19

> Closed alpha · Responsive Main Player display positioning

## Summary

Alpha.19 is a focused Windows QA build following alpha.18. It keeps the default Main Player display content visually centered as the resizable display grows, without scaling the classic typography.

## Changes

- Vertically centers the default Main Player display content relative to the responsive internal screen.
- Keeps the time display, playback indicator, track marquee and spectrum at their existing pixel sizes while the player is resized.
- Adds regression coverage that verifies content repositioning and unchanged font size after expansion.

## Automated validation

- [x] Frontend tests: 7 files, 21 tests passed.
- [x] TypeScript/Vite production build.
- [x] Browser fallback smoke: 7 tests passed.
- The tagged release workflow performs the Windows installer, native-window smoke test and Store preflight for this candidate.

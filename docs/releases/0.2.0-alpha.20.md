# AMP99 v0.2.0-alpha.20

> Closed alpha · Responsive Main Player text/waveform layout

## Summary

Alpha.20 is a focused Windows QA build following alpha.19. It keeps the default Main Player track text clear of the waveform as the responsive display grows, without scaling the classic typography.

## Changes

- Reserves a responsive track-text lane beside the waveform in the default Main Player display.
- Keeps the track text lane expanding with the display while maintaining separation from the waveform.
- Keeps classic font and waveform sizes unchanged.
- Adds regression coverage for no-overlap behavior at expanded size.

- [x] Frontend tests: 7 files, 21 tests passed.
- [x] TypeScript/Vite production build.
- [x] Browser fallback smoke: 7 tests passed.
